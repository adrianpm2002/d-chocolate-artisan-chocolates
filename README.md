# D'ChocolAte Ecommerce




Plataforma de comercio electrónico para la gestión y venta online de productos artesanales de D'ChocolAte.




## Objetivo




Desarrollar un ecosistema de comercio electrónico que permita a los clientes consultar productos, realizar pedidos y dar seguimiento a sus compras, mientras el negocio administra sus productos, pedidos y operaciones.




El sistema se construirá de forma incremental, mediante módulos funcionales independientes e integrados en una arquitectura común.
